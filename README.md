# wowf-feed

Research data for a personal WoW Forever dashboard (Vorgash, Orc Enhancement Shaman, and Corvin, Undead Warlock). One file, `wowf-data.json`, written by a research bot and read by a dashboard on a home network. Format and rules: [DATA_CONTRACT.md](DATA_CONTRACT.md).

Every claim in the data carries its source and the date it was read. Unofficial items stay tagged until Blizzard confirms them.
